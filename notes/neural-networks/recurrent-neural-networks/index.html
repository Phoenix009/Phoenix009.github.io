Recurrent Neural Networks

A Recurrent Neural network is a neural network that is specialized for processing a sequence of values x(1),⋯ ,x(τ)x^{(1)}, \cdots, x^{(\tau)}. Recurrent networks can scale to much longer sequences than would be practical for networks without sequence based specialization.

Parameter sharing makes it possible to extend and apply the model to examples of different forms (here, different lengths) and generalize across them. Such sharing is particularly important when a specific peice of information can occur at multiple positions within the sequence.

A related idea is the use of the convolution across a 1-D temporal sequence. This convolution approach is the basis for time-delay neural networks

The output of convolution is a sequence where each member of the output is a function of a small number of neighboring members of the input. Recurrent networks share parameters in a different way. Each member of the output is a function of the previous members of the output.

Unfolding Computational Graphs:

A computational graph is a way to formalize the structure of a set of computations.

Consider the classical form of a dynamical system

s(t)=f(s(t−1);θ) s^{(t)} = f(s^{(t-1)}; \theta)

The equation states that the current state of the system is a function of the previous state.

For a finite number of timesteps τ\tau we can unfold the equation by applying the definition τ−1\tau - 1 times.

s(3)=f(f(s(1);θ);θ) s^{(3)} = f(f(s^{(1)}; \theta); \theta)

Thus we have unfolded of a recursive computation into a computational graph that has a repeatetive structure. Unfolding this graph results in parameter sharing across a deep network structure.

Consider another example of a dynamic system driven by an external signal.

s(t)=f(s(t−1),x(t);θ) s^{(t)} = f(s^{(t-1)}, x^{(t)}; \theta)

Here, we see that the current state contains information about the whole past sequence. Many recurrent neural networks use the above equation or a similar equation to define the values of their hidden units.

Depending on the training criterion, this summary might selectively keep some aspects of the sequence with more precision than other aspects.

Recurrent Neural Network:

Important design patterns for recurrent neural networks include the following:

  1. Recurrent networks which produce an output at each time step and have recurrent connections between hidden untis
  2. Recurrent networks which produce an output at each time step and have recurrent connection only from the output at one time step to the hidden untis at the nect time step
  3. Recurrent networks that with recurrent connections between hidden units that read an entire sequence and then produce a single output.

We now develop the forward propagation equiations for the RNN\text{RNN}.

We assume a hyperbolic tangent activation function. We also assume that the output is discrete. A natural way to represent discrete variables is to regard the output as giving unnormalized log probabilities of each possbile value of the discrete variable.

We can then apply the softmax function operation as a post-processing step to obtain a vectire y^\hat{y} of normalized probabilities over the output.

a(t)=b+Wht−1+Uxth(t)=tanh⁡(a(t))o(t)=c+Vh(t)y^(t)=softmax(o(t)) a^{(t)} = b + Wh^{t-1} + Ux^{t} \\ h^{(t)} = \tanh(a^{(t)}) \\ o^{(t)} = c + Vh^{(t)} \\ \hat{y}^{(t)} = \text{softmax}(o^{(t)})

The total loss for a given sequence of xx values paired with a sequence of yy values would then be just the sum of losses over all the time steps.

L(t)=−∑tlog⁡pmodel(y(t)∣{x(1),x(2),…x(t)}) L(t) = - \sum_t \log p_{model}(y^{(t)} \mid \{x^{(1)}, x^{(2)}, \dots x^{(t)}\})

BPTT\text{BPTT} - Back Propagation Through Time:

One simply applies the generalized back propagation algorithm to the unrolled computational graph. The use of back propagation to the unrolled graph is called the back propagation through time.

Gradients obtained by back propgation may then be used with any general purpose gradient based techniques to train an RNN\text{RNN}.

Recurrent Networks as Directed Graphical Models:

In principle it is possible to use any loss with a recurrent neural network. We usually wish to interpret the output of the RNN as a probability distribution and we usually use the cross entropy associated with that distribution to define the loss.

When we use use a predicitve log-likelihood training cost, we train the RNN to estimate the conditional distribution of the next sequence element y(t)y^{(t)} given the past inputs

log⁡p(y(t)∣x(1),x(2),…x(t)) \log{p}(y^{(t)} \mid x^{(1)}, x^{(2)}, \dots x^{(t)})

When we feed the actual values yy back into the network, the directed graphical model conatins edges from all y(i)y^{(i)} values in the past to the current y(t)y^{(t)} value.

We can consider the case where the RNN models only a sequence of scalar random variables Y={y(1),y(2),…y(τ)}\mathbb{Y} = \{y^{(1)}, y^{(2)}, \dots y^{(\tau)}\} with no additional inputs xx.

We can then write

P(Y)=P(y(1),y(2),…y(τ)) P(\mathbb{Y}) = P(y^{(1)}, y^{(2)}, \dots y^{(\tau)})

Where

L(t)=−log⁡P(y(t)=y(t)∣{y(1),y(2),…y(t−1)}) L^{(t)} = -\log P(y^{(t)} = \texttt{y}^{(t)} \mid \{y^{(1)}, y^{(2)}, \dots y^{(t-1)}\})

To complete our view of an RNN as a graphical model, we must decribe how to draw samples from the model. We must also have some mechanism for determining the length of the sequence.

One can add a special symbol that correspinds to the end of a sequence. When this symbol is generated the sampling process stops.

Another option is to add an extra bernoulli output to the model that represents the decision to either continue generation or halt the generation.

another way to determine the sequence length τ\tau is to add an extra output to the model that predicts the integer τ\tau itself. The model can sample a value of τ\tau and then sample τ\tau steps worth of data.

Modelling sequences Conditioned on Contexts:

In, general, RNNs allow the extension of the graphical model to represent conditional distribution over yy given xx.

In case of RNNRNN this can be acheived in different ways.

The interaction between the input xx and each hidden unit vector h(t)h^{(t)} is parameterized by a newly introduced weight matrix RR. The product x⊤Rx^{\top}R is added as additional input to the hidden units at every time step.

Rather than receiving only a single vector xx as input, RNN may receive a sequence of vectors x(t)x^{(t)} as input. The model given above corresponds to a distribution that makes conditional independence assumptions.

To remove conditional independence assumption, we can add connections from the output at time tt to a hidden unit at time t+1t+1.

Bidirectional RNNs:

All of the RNNs considered up to now have a causal structure meaning that the state at time tt only captures information from the past and the present input.

However, in many applications we want to output a prediction whichi may depend on the whole input sequence.

Bidirectional RNNs were designed to address this need. They combine a RNN that moves forward with another RNN that moves backwards.

This allows the output unit to compute a representation that depends on both the past and the future but is most sensitive to the input values at time tt.

Encoder-Decoder Sequence-to-Sequence Architecture:

How an RNN can be trainied to map an input sequence to an output sequence which is not necessarily of the same length.

We introduct a context CC which is a vector or a sequence of vectors that summarize the input sequence.

The idea is very simple:

  1. an encoder processes the input sequence and emits the context.
  2. a decoder is conditioned on the context to generate the output sequence YY

If the context CC is a vector, then the decoder RNNRNN is simply a vector to sequence RNNRNN.

Thus input can be given in two ways:

  1. As an initial state of the RNNRNN
  2. As an input to the hidden units at each time stamp.

One limitation is if the context CC has a dimension that is too small to properly summarize a long sequence.

Deep Recurrent Networks:

The computation in RNNRNN can be decomposed into three transformations:

  1. Input to Hidden
  2. Hidden to Hidden
  3. Hidden to Output

Each of these block is associated with a single weight matrix. This is a transformation is represented by an affine transformation followed by a fixed non-linearity.

Recursive RNNs:

The Challenge of Long Term Dependencies:

The basic problem is that gradienst propagated over many stages tend to either vanish or explode.

the function composition employed by the RNN\text{RNN} resembles matrix multiplication

h(t)=W⊤h(t−1) h^{(t)} = W^{\top} h^{(t-1)}

The recurrent relation applied tt times can be written as

h(t)=(Wt)⊤h(0)h(t)=Q⊤ΛtQh(0) h^{(t)} = (W^t)^{\top} h^{(0)} \\ h^{(t)} = Q^{\top} \Lambda^t Q h^{(0)}

How is this problem avoided in FFN\text{FFN}?

Suppose that the weights w(t)w^{(t)} are generated randomly,x independently from one another, with zero mean and variance vv. The variance of the product is O(vn)O(v^n). To obtain some desired variance v∗v^* we may choose the individual weights with variance v=v∗v = \sqrt{v^*}. Thus very deep FFN\text{FFN} with carefully chosen scaling can this avoid the vanishing and exploding gradient problem.

Specifically, whenever the model is able to represent long term dependencies, the gradient of the long term interaction has exponentially smaller magnitude than the gradient of a short term interaction.

Thus it takes a very long time to learn the long-term dependencies.

the experimets show that as we increase the span of the dependencies that need to be captured, gradient based optimization becomes increasingly difficult.

Echo State Networks:

The recurrent weights mapping from h(t−1)h^{(t-1)} to h(t)h^{(t)} and the input weights mapping from x(t)x^{(t)} to h(t)h^{(t)} are the most difficult parameters to learn in a recurrent network.

ESN approach to avoiding this difficulty is to only learn the output weights (h(t)h(t) to o(t)o(t)). Set the recurrent weights such that the recurrent hidden units do a good job of capturing the history of the past inputs.

The training criterion may then be easlity designed to be convex as a function of the output weights.

The important question is how to set the input and recurrent weights so that a rich set of histories can be represented?

Leaky units and other strategies for Multiple Time Scales:

One way to deal with long-term dependencies is to design a model that operates at multiple time scales, so that some parts of the model operate at fine grained time scales, while other parts operate at coarse time scales and transfer information from the distant past to present.

1. Adding skip connections:

In ann ordinary RNN\text{RNN} a recurrent connection goes from a unit at time tt to a unit at time t+1t+1. It is possible to construct a recurrent networks with longer delays.

2. Leaky Units:

μ(t)=αμ(t−1)+(1−α)x(t−1) \mu^{(t)} = \alpha \mu^{(t-1)} + (1 - \alpha) x^{(t-1)}

When

  1. α\alpha is near 1, remembers the information about the past
  2. α\alpha is near 0, information about the past is discarded

Such a hidden unit is called a leaky unit.

Skip connections through time dd are a way of ensuring that a unit can always learn to be influence by the information from dd time steps earlier.

There are two basic strategies for setting the time constants. used by leaky units:

  1. Manually fix them to values that remain constant.
  2. Make time constants free parameters and learn time.

LSTM\text{LSTM} and other gated RNNs\text{RNN}s:

Leaky units allow the network to accumulate information. However, once that information is used, it might be useful to forget the old state.

Instead of manually deciding when to clear the state, we want the network to learn to decide when to do it. This is what gated RNNs\text{RNN}s do

LSTM\textbf{LSTM}:

A crucial addition has beem to make the weight of the connection from h(t)h^{(t)} to h(t+1)h^{(t+1)} be conditioned on the context CC.

By making the weights gated, the time scale of integraion can be changed dynamically.
