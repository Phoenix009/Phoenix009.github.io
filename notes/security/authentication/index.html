Authentication

The theoretical number of possible combinations

∣A∣L |A|^L
  • AA - set of possible characters
  • LL - length of the password

The bits of entropy ee:

e=L×log⁡(A)log⁡(2) e = L \times \frac{\log(A)}{\log(2)}

The number of possible passwords:

2e 2^e
